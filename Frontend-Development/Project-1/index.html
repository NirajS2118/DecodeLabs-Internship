Core Curriculum

Engineering Principles

Every concept taught in this track maps directly to production-quality frontend engineering.

  • 🏗️

    Semantic HTML

    Structure your document using the right elements. Semantic tags communicate meaning to browsers, search engines, and assistive technologies — not just visual browsers.

    • <header>
    • <main>
    • <nav>
    • <footer>
    • <article>
  • 🎨

    CSS Architecture

    External stylesheets only. BEM naming keeps classes reusable and scoped. CSS Custom Properties make your design system a single source of truth.

    • BEM
    • DRY
    • Custom Properties
    • No Inline Styles
  • 📐

    Layout Systems

    CSS Grid handles macro page structure — rows, columns, named areas. Flexbox handles micro component alignment. Use the right tool for each job.

    • CSS Grid
    • Flexbox
    • Responsive
  • ♿

    A11Y Standards

    Accessibility is non-negotiable. Alt text on every image, contrast ratio above 4.5:1, keyboard navigation, and proper ARIA landmarks throughout.

    • Alt Text
    • ARIA
    • 4.5:1 Contrast
    • WCAG 2.1
  • 🖼️

    Asset Integrity

    Set explicit width and height on every image to prevent Cumulative Layout Shift. Prefer AVIF and WebP with JPEG as the legacy fallback.

    • AVIF
    • WebP
    • Explicit Dimensions
    • No CLS
  • ✅

    Quality Gate

    Code does not ship until it passes the audit: W3C HTML validation with zero errors, semantic landmark review, and Lighthouse performance score.

    • W3C Valid
    • Lighthouse
    • Zero Errors
