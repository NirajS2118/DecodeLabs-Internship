The Process

Execution Roadmap

Six stages from discovery to deployment.

  1. 01

    Discovery

    Define "How Might We" questions. Use Empathy Maps to uncover user pain points.

  2. 02

    Wireframe

    Grayscale, mobile-first. Focus on hierarchy and flow. If it doesn't work in grayscale, color won't fix it.

  3. 03

    Semantics

    HTML Landmark elements. Semantic tags provide a Table of Contents for screen readers and AI.

  4. 04

    Style

    CSS Grid/Flex & 2025 Palette — Mocha Mousse, Ethereal Blue, Moonlit Grey.

  5. 05

    Logic

    State & Interactivity. DOM manipulation, event delegation, accessible components.

  6. 06

    Audit

    LCP/CLS & Accessibility. Lighthouse scores, WCAG 2.1 AA compliance, performance audit.
